# Personal Task Tracking

Tasks are stored in `localStorage` under `civicsathi.personalTasks.v1`, only after a user chooses to save one. They are isolated to the current browser profile, not synchronized, and visible to people who share that browser profile. The dashboard supports task creation, category, status change, deletion, and clear-all.

Statuses are Not Started, In Progress, Ready for Official Portal, Completed by User, and On Hold. CivicSathi never changes a task to completed based on a government event. These are personal preparation tasks, not live application tracking. Do not save Aadhaar/PAN values, credentials, OTPs, exact private addresses, or other sensitive notes. Use the delete controls or browser site-data controls to remove tasks.
