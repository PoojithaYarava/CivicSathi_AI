# CivicSathi Project Overview

CivicSathi is an independent local information assistant for public services across all 33 Telangana districts. It searches project catalogues, returns source-attributed matches, and presents researched document requirements with case and jurisdiction context. It also helps prepare an unsent civic complaint draft and redirects citizens to recorded official channels.

The app is not a government portal and does not submit applications, complaints, payments, or status checks. Query analysis is processed in memory. Optional personal preparation tasks are saved in the user's current browser profile only. Review source information and current rules on the government site before acting.

Supported query text includes English, Telugu script and Telugu-English forms as represented in project data. The UI offers English, Telugu help, or bilingual checklist labels; source facts and government document names remain in their published wording. Most of the interface remains English. Language identification is heuristic. Voice support is optional browser speech recognition; processing may occur outside the device, and code-mixed speech quality has not been measured.
