# Documents and Forms

The `/api/documents` catalogue returns the six existing form/document rows. A record can display name, purpose, related service, category/type, department, destination link, source page, and verification warnings. A present URL is not proof that the file remains available.

Scenario-specific checklists are stored separately in `service_document_requirements.csv`. Each item retains source, jurisdiction, scenario, required/conditional/alternative/prerequisite/format classification and conditions. Checkboxes are page state only. Copy and print are user initiated; no checklist completion is submitted to a service. No unverified universal document list is generated.
